# MyPitchfork UI 视觉优化计划

## 1. 目标

在不改变任何业务逻辑、数据结构和用户操作流程的前提下，统一优化网页操作界面、实时海报预览与 PNG 导出效果，使产品呈现为现代、简洁、克制的极简编辑工具。

本次视觉关键词：

- 淡白背景
- 中性灰黑
- 清晰排版
- 细线边界
- 轻微圆角
- 克制动效
- 少量红色状态强调

## 2. 已确认的设计决策

| 项目 | 最终决策 |
| --- | --- |
| 整体方向 | 极简中性风 |
| 页面背景 | 淡白色，不使用深色模式 |
| 主色体系 | 淡白、暖灰、深灰黑 |
| 功能强调色 | 仅“喜欢”和总评分 `>= 90` 时保留红色 |
| 字体组合 | 本地托管 Inter + Source Serif 4 |
| 桌面布局 | 左侧编辑、右侧实时预览的双栏结构 |
| 移动端顺序 | 编辑区优先，完整预览随后 |
| 信息密度 | 主要表单舒展，曲目编辑列表相对紧凑 |
| 圆角 | 统一使用约 `6–8px` 的轻微圆角 |
| 阴影 | 仅关键层级使用极淡阴影 |
| 动效 | 适中且克制，并支持减少动态效果 |
| 海报结构 | 保留标题、封面与圆形评分并排、曲目列表在下的现有结构 |
| 总评分 | 保留现有圆形评分形式和位置关系 |
| 海报外框 | 保留单层外框，改为更细的深灰线 |
| 封面阴影 | 改为非常淡的柔和阴影 |
| 顶部标识 | 保留 `BERLEY ALBUM REVIEW`，改为纯深灰排版 |
| 导出尺寸 | 固定 `1200px` 宽，高度继续随内容自动增长 |
| 文案范围 | 按钮和字段名称不变，只允许精简辅助说明 |
| 示例产物 | 不重新生成或修改 `out/` 中的现有 PNG |

## 3. 范围边界

### 3.1 本次允许修改

- 页面颜色、排版、间距、边框、圆角和阴影。
- 桌面端双栏比例与移动端排列顺序。
- 按钮、输入框、卡片、搜索结果、提示与空状态的视觉表现。
- 悬停、聚焦、列表出现、编辑区域出现及预览更新的展示动效。
- DOM 海报预览的视觉样式。
- Canvas PNG 的绘制参数、字体、颜色、线宽、间距与阴影。
- 为视觉一致性新增本地字体资源及字体授权文件。
- 必要的纯展示类名或动效触发代码，但不得影响功能状态和事件结果。

### 3.2 明确禁止修改

- iTunes 搜索和 Lookup API 的地址、参数、JSONP 流程及数据转换。
- 草稿数据结构、`localStorage` 键值、读取与保存机制。
- 搜索、选择专辑、手动创建、添加或删除曲目、清空和下载流程。
- 总分与单曲评分的范围、取整、必填和校验规则。
- `liked`、`overallScore`、`tracks` 等字段的含义。
- 总评分 `>= 90` 的红色强调条件。
- PNG 文件命名与下载方式。
- 新增深色模式、主题切换、模板切换或导出规格选项。
- 修改或覆盖 `out/` 目录内已有示例图片。
- 引入 UI 框架、动画库或其他运行时依赖。

## 4. 视觉基础规范

### 4.1 颜色令牌

在 `src/styles.css` 的 `:root` 中集中定义并复用以下语义色，移除当前蓝色焦点和绿色栏目色：

| 令牌 | 建议值 | 用途 |
| --- | --- | --- |
| `--page` | `#F3F2EE` | 页面淡白背景 |
| `--surface` | `#FCFBF8` | 面板与控件背景 |
| `--surface-subtle` | `#F7F6F2` | 次级区域、空状态和预览舞台 |
| `--ink` | `#1B1A18` | 主文字、主按钮、主要描边 |
| `--ink-soft` | `#4E4B46` | 次级正文 |
| `--muted` | `#77736C` | 标签、说明和辅助信息 |
| `--line` | `#D8D5CE` | 常规边框和分隔线 |
| `--line-strong` | `#AAA69E` | 聚焦与重要边界 |
| `--accent-red` | `#C9252D` | 喜欢和 90 分以上状态 |
| `--danger-bg` | `#FFF3F2` | 错误或未完成提示底色 |

颜色约束：

- 普通交互焦点使用深灰描边与半透明灰色焦点环，不再使用蓝色。
- 主按钮保持深灰黑底和淡白文字。
- 选择态使用深灰边框、浅灰底或内描边，不增加新强调色。
- 红色不得用于普通按钮、链接、标题或装饰。

### 4.2 字体

新增本地字体目录，例如：

```text
src/assets/fonts/
  Inter-Variable.woff2
  SourceSerif4-Variable.woff2
  OFL-Inter.txt
  OFL-SourceSerif4.txt
```

字体使用规则：

- Inter 用于网页界面、海报辅助信息、艺术家名、评分数字和曲目列表。
- Source Serif 4 仅用于评分图中的专辑标题，形成编辑杂志感。
- 中文与缺失字形依次回退到 `PingFang SC`、`Microsoft YaHei`、系统无衬线或衬线字体。
- 使用 `font-display: swap`，避免字体加载阻塞页面。
- 在 `index.html` 中预加载两个 WOFF2 文件，减少首次预览时的字体跳变。
- Canvas 导出前确认字体已就绪，保证实时预览与 PNG 的文本测量尽量一致；该等待仅属于渲染准备，不得改变下载校验或下载流程。

### 4.3 字号和字重

- 页面标题：Inter，`20–22px`，`700`。
- 区块标题：Inter，`15–16px`，`650–700`。
- 字段标签：Inter，`12–13px`，`600`。
- 正文与输入：Inter，`14–15px`，`400–500`。
- 辅助文字：Inter，`12–13px`，`400–500`。
- 海报专辑名：Source Serif 4，粗体，维持醒目但降低当前过度厚重感。
- 分数与曲目数字启用等宽数字特性 `font-variant-numeric: tabular-nums`。

### 4.4 圆角、边框和阴影

- 主面板：`8px` 圆角、`1px` 边框。
- 输入框与按钮：`6px` 圆角、`1px` 边框。
- 搜索结果和曲目行：`6px` 圆角。
- 页面关键面板阴影控制在低透明度、大扩散范围，例如 `0 8px 28px rgba(27, 26, 24, 0.045)`。
- 普通控件、曲目行和提示不使用独立投影。
- 海报预览可使用极淡投影以区别于预览舞台，但导出 PNG 内不添加整张海报投影。

## 5. 网页界面调整

### 5.1 页面背景与顶部栏

- 移除当前网格纹理背景，改为纯淡白页面底色。
- 顶部栏继续固定，但缩减视觉重量：使用单像素底边、半透明淡白背景和极淡阴影。
- `MyPitchfork` 使用正常大小写或现有文字内容，不增加装饰性颜色。
- 保持“刷新”和“下载 PNG”按钮名称、用途与位置不变。
- 主操作按钮使用深灰实心样式；次操作使用淡白底与灰色细边框。

### 5.2 双栏工作区

- 保留现有双栏，不改变功能分区。
- 桌面端建议使用 `minmax(380px, 480px) minmax(0, 1fr)`，左栏稳定、右侧预览尽可能获得空间。
- 工作区最大宽度保持约 `1440–1500px`，栏间距约 `24px`。
- 左栏各面板间距统一，右侧预览区域保持独立面板层级。
- 页面滚动仍使用浏览器自然滚动，不新增复杂固定区域或内部滚动逻辑。

### 5.3 表单与按钮

- 统一输入框、选择框、文本域的高度、内边距和边框颜色。
- 聚焦态使用 `2px` 以内的深灰边框配合柔和外环，确保键盘操作可见。
- 禁用态降低对比度但仍保持文字可读，不只依赖透明度表达。
- 删除按钮维持中性外观，仅在悬停或聚焦时显示轻微红色危险提示。
- 心形按钮未选中时为中性空心或低对比状态，选中后使用红色实心状态。
- 保持现有按钮、输入字段名称和所有点击行为不变。

### 5.4 搜索结果

- 缩略图保持方形，圆角与卡片统一。
- 专辑名、艺术家、年份/曲目数/类型建立清晰的三级文字层级。
- 默认卡片使用浅底细边框；悬停时轻微上移并增强边框；选中态用深灰内描边和浅灰背景。
- “选择/载入中”文字仍在原有位置和状态逻辑下显示。
- 多条结果使用轻微交错出现，但不得延迟用户点击。

### 5.5 评分编辑器

- 专辑元数据区域保持两列，宽字段继续跨列。
- 曲目工具栏与元数据区增加明确但不过重的间隔。
- 曲目表头降低对比度；曲目行更紧凑，维持长专辑的编辑效率。
- 曲名获得主要宽度，时长、喜欢、评分和删除保持稳定窄列。
- 未完成曲目继续使用现有校验条件，只将视觉改为淡红背景或红色细边框。
- 所有输入框、按钮、`aria-label` 和键盘操作保持有效。

### 5.6 提示与辅助文案

按钮和字段文字保持不变，只调整辅助说明：

- `等待选择专辑` 可改为 `选择专辑或手动创建后，即可开始评分。`
- `未找到结果` 可改为 `没有找到匹配的专辑，请尝试其他关键词或地区。`
- `还没有曲目，请添加第一首` 保持含义，可统一标点与语气。
- 错误、通知和待完成提示继续由现有状态驱动，不改变出现条件。

## 6. 响应式布局

### 6.1 桌面端

- 宽度大于 `980px` 时保持左编辑、右预览双栏。
- 预览画布在可用空间内等比缩放，不修改实际导出尺寸。

### 6.2 平板与移动端

- 宽度不超过 `980px` 时改为单栏，顺序必须为：专辑导入 → 评分编辑 → 海报预览。
- 移除当前移动端 `.preview-area { order: -1; }` 行为。
- 宽度不超过 `680px` 时，搜索表单、元数据表单和顶部操作自然换行。
- 移动端按钮触控高度不低于 `40–44px`。
- 曲目行允许曲名独占第一行，其余字段在第二行紧凑排列。
- 最窄验收宽度为 `320px`，不得出现页面级水平滚动；海报舞台内部可保留必要的缩放或滚动策略。

## 7. 动效规范

### 7.1 动效层级

| 场景 | 建议时长 | 效果 |
| --- | --- | --- |
| 按钮、输入框悬停/聚焦 | `120–160ms` | 颜色、边框、背景平滑过渡 |
| 搜索结果出现 | `180–220ms` | 透明度 `0 → 1`，上移量不超过 `6px` |
| 编辑区域出现 | `180–220ms` | 淡入并轻微上移 |
| 预览更新 | `120–160ms` | 极轻透明度恢复或不超过 `2px` 的位移 |
| 心形状态切换 | `140–180ms` | 颜色切换并轻微缩放，禁止弹跳 |
| 面板/卡片悬停 | `140–180ms` | 边框、阴影与不超过 `2px` 的位移 |

统一使用自然的 `ease-out` 或近似缓动，不使用弹簧、旋转、强缩放或长距离位移。

预览会在输入过程中频繁重绘，因此更新动画必须非常轻，并确保连续输入时不闪烁、不阻碍文本输入。优先使用 CSS 动画；只有在 CSS 无法稳定控制重复触发时，才允许增加不读写业务状态的展示辅助函数。

### 7.2 减少动态效果

增加 `@media (prefers-reduced-motion: reduce)`：

- 关闭进入和位移动画。
- 将非必要过渡时长降为接近 `0ms`。
- 保留立即可见的悬停、聚焦和状态差异。

## 8. 评分图片与实时预览

### 8.1 结构保持不变

继续使用以下顺序：

1. `BERLEY ALBUM REVIEW`
2. 专辑名
3. 艺术家名
4. 左侧专辑封面与右侧圆形总评分
5. 简评（存在时）
6. 曲目列表

不改变圆形总评分的基本形式，不改变封面和评分左右并排的关系。

### 8.2 海报基础视觉

- 背景改为干净的暖淡白色，避免明显纸张纹理。
- 外框由当前粗黑线改为约 `2px` 的深灰线，并保持充分内边距。
- `BERLEY ALBUM REVIEW` 全部使用 Inter 和深灰色；通过字重或透明度区分两部分，不使用红绿品牌色。
- 专辑标题使用 Source Serif 4 粗体，艺术家名和其余信息使用 Inter。
- 标题仍居中，适当增加标题与艺术家之间的留白。

### 8.3 封面与评分

- 封面尺寸和位置关系基本保持现状。
- 封面保留细边框，将当前右下错位硬阴影改为自然柔和阴影。
- DOM 使用低透明度、较大模糊半径的 `box-shadow`。
- Canvas 使用 `shadowColor`、`shadowBlur` 和小幅 `shadowOffsetY` 绘制相近效果。
- 普通评分圆使用深灰描边与淡白填充。
- `>= 90` 时继续使用红色描边和红色数字，阈值及判断方式不变。

### 8.4 简评与曲目列表

- 简评继续位于上下分隔线之间，但将粗线改为细线。
- 适度增加简评行高，降低字重，提高长文本可读性。
- 曲目列表保持现有列顺序：序号、曲名、时长、喜欢、评分。
- 表头不新增，避免改变海报信息结构。
- 横向分隔线统一减细并降低对比度。
- 曲名使用中等字重；时长和序号使用较浅文字；评分保持清晰的深灰粗体。
- 喜欢状态继续使用红色实心心形。
- `poster--dense` 与 `poster--extended` 的触发条件保持不变，只重新校准字号和行高。

### 8.5 DOM 与 Canvas 一致性

DOM 预览和 Canvas 导出必须共用同一套视觉常量，至少确保以下项目一致：

| 项目 | 一致性要求 |
| --- | --- |
| 背景与红色 | 使用相同十六进制色值 |
| 字体 | 使用相同字体家族、用途和近似字重 |
| 外框 | 视觉粗细按缩放比例一致 |
| 标题层级 | 字体类型、对齐和相对间距一致 |
| 封面阴影 | 方向、柔和程度和透明度一致 |
| 评分圆 | 描边比例、填充、字号和高分状态一致 |
| 简评分隔线 | 颜色和相对粗细一致 |
| 曲目列 | 顺序、对齐、颜色层级和紧凑模式一致 |

Canvas 仍保持 `1200px` 宽度及内容驱动的动态高度。允许为新字体和新间距重新计算绘制坐标及最终高度，但不得改成固定比例、分页或裁切内容。

- 调整双栏比例和移动端顺序。
- 增加进入、悬停、状态切换及 `prefers-reduced-motion` 规则。

### `index.html`

- 预加载本地 Inter 与 Source Serif 4 字体。
- 仅在需要时调整辅助说明或空状态文字。
- 保持按钮、字段、表单 ID、DOM 功能结构和脚本入口不变。

### `src/poster/canvas-renderer.js`

- 将 Canvas 的颜色、字体、线宽、阴影与间距更新为新视觉规范。
- 保留 1200px 宽度、动态高度、内容顺序、评分阈值与下载行为。
- 用柔和 Canvas 阴影替换错位矩形阴影。
- 为专辑标题使用 Source Serif 4，其余内容使用 Inter。

### `src/lib/canvas-text.js`

- 扩展 `canvasFont()`，使其可明确选择无衬线或衬线字体栈。
- 保持换行、截断、行数限制和绘制辅助函数的输入输出行为不变。

### `src/poster/dom-renderer.js`

- 原则上保留现有节点顺序和数据绑定。
- 只有在样式无法表达所需层级时才新增纯展示类名或包裹元素。
- 不修改高分、喜欢、紧凑模式和空状态的判断条件。

### `src/app.js`

- 默认不修改。
- 仅当预览更新动画无法通过 CSS 稳定实现时，允许加入独立的展示辅助函数；不得新增业务状态、修改事件处理结果或改变保存/下载流程。

### `src/assets/fonts/`（新增）

- 放置 Inter 与 Source Serif 4 的 WOFF2 字体文件。
- 同步保存对应的开源字体授权文本。
- 字体文件名、`@font-face` 名称和 Canvas 字体名称必须一致。

### `out/`

- 不做任何修改。

## 10. 推荐实施顺序

1. 引入并验证本地字体及授权文件。
2. 建立 CSS 视觉令牌，完成页面背景和基础排版。
3. 优化顶部栏、面板、表单、按钮和提示状态。
4. 优化搜索结果和评分编辑器，并完成响应式调整。
5. 完成 DOM 海报预览样式。
6. 按 DOM 视觉参数同步修改 Canvas 绘制。
7. 添加克制动效和减少动态效果支持。
8. 进行功能回归、跨尺寸检查和 DOM/PNG 对照验收。

每一步都应单独确认页面仍可完成原有流程，避免把纯视觉调整与功能修改混在一起。

## 11. 验收清单

### 11.1 视觉验收

- 页面为干净的淡白背景，不再出现网格纹理。
- 普通界面仅使用淡白和灰黑；红色只出现在喜欢、高分及必要的错误状态。
- Inter 和 Source Serif 4 均从本地加载，断网时仍可使用。
- 卡片、按钮和输入框使用统一轻微圆角。
- 阴影轻微，内容层级主要依靠留白、底色和细边框建立。
- 桌面端保持左编辑、右预览；移动端编辑区先于预览。
- DOM 海报与导出 PNG 的字体、颜色、间距和层级观感一致。
- 海报保留现有结构和圆形评分，外框更细，封面阴影更柔和。
- `BERLEY ALBUM REVIEW` 保留且为深灰单色。
- 喜欢状态和 `>= 90` 的总评分继续为红色。

### 11.2 动效验收

- 搜索结果和编辑区出现时有轻微淡入上移。
- 按钮、输入框、卡片和心形状态切换平滑且不夸张。
- 连续输入时海报预览不闪烁、不抖动、不影响输入响应。
- 开启系统“减少动态效果”后，非必要动画关闭。

### 11.3 响应式验收

- 在约 `1440px`、`1024px`、`768px`、`390px` 和 `320px` 宽度下检查布局。
- `> 980px` 为双栏，`<= 980px` 为编辑优先的单栏。
- 页面级无意外水平滚动，文字和控件不重叠。
- 移动端曲目输入仍可完整编辑，所有按钮均容易点击。

### 11.4 海报内容验收

分别检查：

- 空白草稿。
- 短标题和长标题。
- 中文、英文及混合语言标题。
- 无简评和接近 180 字的简评。
- 普通曲目数、`17–22` 首和超过 `22` 首的专辑。
- 未评分、普通评分、89 分、90 分和 100 分。
- 无喜欢曲目和多个喜欢曲目。
- 封面正常加载与封面加载失败的占位状态。

### 11.5 功能回归

确认以下行为与修改前完全一致：

- 搜索专辑及地区选择。
- 选择搜索结果并载入曲目。
- 手动创建专辑。
- 编辑专辑名、艺术家名、封面 URL、总评分和简评。
- 编辑曲名、时长、喜欢和单曲评分。
- 添加、删除曲目和清空草稿。
- 待完成数量、错误提示和按钮禁用状态。
- 刷新后从 `localStorage` 恢复草稿。
- 下载 PNG，文件名规则不变。
- 导出画布宽度仍为 `1200px`，高度随内容变化。
